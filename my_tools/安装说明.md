## 启动 / 停止

```bash
# 启动（在项目根；必须在会话内跑时用 PYTHONPATH= 置空，不要用 env -u PYTHONPATH）
# 日志重定向到 my_tools/log/，避免在项目根堆 livetalking.log
cd /e/work/LiveTalking
PYTHONPATH= .venv/Scripts/python.exe -u app.py --transport webrtc --model wav2lip \
  --avatar_id lady_presenter --listenport 8010 > my_tools/log/app_8010.log 2>&1

# 验证（另开终端）
.venv/Scripts/python.exe my_tools/webrtc_smoke.py     # WebRTC 握手 + 抓帧
.venv/Scripts/python.exe my_tools/lipsync_test.py     # TTS 说话 + 口型帧差分析
```

网页预览：http://127.0.0.1:8010/webrtc.html （防火墙需放行 TCP 8010 + UDP）

## 踩坑记录（本会话实测）

1. **WorkBuddy 会话里 `python -m venv` / `py -3.12 -m venv` 静默失败**：退出码 0 但什么都不建。
   解法：用 `venv.EnvBuilder` 直接调（`my_tools/make_venv.py`），或 PowerShell/系统终端里跑。
2. **`env -u PYTHONPATH` 会让部分 python 子进程静默不执行**（退出 0 无输出）；
   带着原 PYTHONPATH 或写 `PYTHONPATH=`（置空）反而正常。与技能文档写的相反，以实测为准。
3. 会话内子进程 stdout 被吞 → 一律 `> 文件 2>&1` 再读文件。
4. 后台任务（run_in_background）曾出现"秒退无输出"，先查 cwd 是不是没 cd（绝对路径启动）。
5. wav2lip256 的 face 输入是 **256x256**（模型末层 k=4 要求边长为 64 的倍数；app.py warm_up 传 256）。
6. 静态单帧头像可用（mirror_index 环回），口型区动画正常；下巴接缝有轻微伪影，换真视频头像可改善。
7. base_avatar.py 会在每帧左上角画 "LiveTalking" 小水印（项目自带标识，代码在 `avatars/base_avatar.py:449`）。
8. 官方头像生成器 `avatars/wav2lip/genavatar.py` 只吃视频（--img_size 要传 256）；
   静态图片先转成 2 秒静帧 mp4 再走官方脚本。
   `my_tools/make_avatar.py` **已废弃**：它把 S3FD 竖长框扩成正方形，crop 变中景，
   导致「嘴不张开 + 下巴变形」，仅作历史参考（原因见 `docs/avatar-pipeline.md` 第五节）。

## 目录规矩（根目录同步，产物进子目录）

`my_tools/` 根目录下的脚本与文档**随仓库同步**；三个子目录不入库：

| 位置 | 放什么 | git |
|---|---|---|
| `my_tools/`（根） | `*.py` / `*.js` 脚本、`*.md` 说明 | ✅ 同步 |
| `my_tools/log/` | 运行日志 `*.log` | ❌ 忽略 |
| `my_tools/image/` | 可视素材：抓帧、截图、候选视频（png/jpg/mp4） | ❌ 忽略 |
| `my_tools/_tmp/` | **纯临时文件**：下载包、调试 dump、一次性探测输出 | ❌ 忽略 |

- 脚本里统一 `from paths import LOG_DIR, IMAGE_DIR, TMP_DIR`（见 `my_tools/paths.py`），
  临时文件用 `TMP_DIR / "xxx"`，别硬编码绝对路径。
- 命令行临时输出（curl dump、探测 json、命令回显）同样写进 `my_tools/_tmp/`。
- **根目录只放代码与文档**：产物（日志 / 素材 / 临时）一律进对应子目录，
  否则会跟着一起提交上去。`_tmp/` 可随时整目录清空。

## 常用脚本

| 脚本 | 作用 |
|---|---|
| `gen_video_t2v.py` | 纯文生视频（不接首帧）：角色长相由提示词 + seed 决定 |
| `gen_idle_video.py` | 图生视频待机动作：`--image` 底图、`--prompt-file` 提示词、首尾同帧 |
| `gen_clip_set.py` | 批量生成多片段素材（读 `clips_v1.py`，每段首尾=起点帧） |
| `build_clip_avatar.py` | 拼接片段 → 官方 genavatar → 写 `clips.json`（多片段头像） |
| `compose_gesture_idle.py` | 主循环 + 插入式微动作，源帧层 crossfade 合成长序列 |
| `check_source_video.py` | 素材预检：检出率 / 脸占比 / 逐帧头动 / 嘴部开合度 |
| `stabilize_head.py` | 头部稳定化（**仅头动大/检测抖的素材需要**，会拉伤脖颈） |
| `lipsync_ab_test.py` | 口型 A/B：静默基线 vs 说话，输出嘴型条带供目检 |
| `airi_cafe_check.js` | airi 端到端：下拉 / 切换 / 视频流 / 播放帧（参数为 avatar id） |
